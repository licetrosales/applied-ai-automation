#ADR-002 AI Classification Categories

## Status

Accepted

## Context

The AI needs consistent categories for newsletter classification.

If categories overlap too much, the workflow becomes difficult to maintain.

## Decision

Use the following categories:

- Cybersecurity Fundamentals
- LLMs and AI
- Make.com / n8n / Automation
- Open Source Security Tools
- Raspberry Pi / Homelab / Network Security
- Application Security
- Cloud / Infrastructure Security
- Hands-on Project Ideas
- Not Relevant

## Consequences

The categories are broad enough to classify all current newsletters while remaining extensible.

Future versions may introduce subcategories.
