# Make.com Workflow

This directory contains the implementation artifacts for the automation workflow.

## blueprints/
Exported Make.com scenarios used for version control.

## screenshots/
Visual documentation of workflow evolution by sprint.

## Screenshot & Data Handling Policy

All screenshots in this folder redact personally identifiable information 
before publishing: sender name/email, message snippets, and full body 
content. Only structural/config data (field names, filter settings, 
operation counts) is shown unredacted. This mirrors the data-handling 
approach described in `docs/architecture.md`.

## notes/
Relevant notes regarding the blueprints and screenshots.
