# Sprint 2 – Email Processing

## Sprint Goal

Process emails retrieved from Gmail so that only relevant newsletters
continue through the automation workflow and clean newsletter content
is available for downstream AI classification.

---

## Sprint Backlog

- [ ] Define newsletter filtering criteria
- [ ] Configure sender/content filtering in Make.com
- [ ] Validate accepted and rejected emails
- [ ] Identify the appropriate email body field
- [ ] Extract newsletter body content
- [ ] Normalize content for downstream AI processing
- [ ] Validate processed email output

---

## Deliverables

- Working newsletter filtering logic
- Validated email body extraction
- Clean newsletter content available for AI classification
- Screenshots documenting key Make.com configuration and test results

---

## Out of Scope

- DeepSeek prompt implementation
- JSON classification output
- Google Sheets storage
- Digest generation
